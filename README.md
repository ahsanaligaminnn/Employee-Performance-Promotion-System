# Employee Performance & Promotion System

A Python-based command-line application that evaluates employee performance and determines promotion eligibility and bonus categories using predefined criteria.

## Features

- Employee information input
- Experience and performance evaluation
- Completed project requirements
- Late-day checks
- Promotion eligibility assessment
- Junior, Mid-Level, and Senior promotion categories
- Bonus percentage calculation
- Input validation using Python string methods

## Promotion Criteria

- Senior: Performance score of 90–100 and at least 5 years of experience
- Mid-Level: Performance score of 80–89 and 3 to 4 years of experience
- Junior: Performance score of 70–79

Employees must also meet the system's minimum experience, project completion, and attendance-related criteria.

## How to Run

Ensure Python is installed on your computer.

Run the following command:

```bash
python employee_performance.py
```
